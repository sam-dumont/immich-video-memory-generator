# Step 3: Generation Options

This step controls what the final video looks and sounds like. The sidebar calls it **Options**.

<ThemedScreenshot name="step3-options" alt="Step 3: Generation Options" />

## Output settings

Two selects are always visible:

- **Resolution**: **Auto (match clips)** (default), 4K, 1080p, 720p. Auto picks the tier of your source clips; 720p renders fastest, 4K needs the source material and the patience.
- **Output Format**: MP4 (H.264), MP4 (H.265), MOV (H.264), MOV (H.265), MOV (ProRes). The default follows `output.codec` and `output.format` in your config — MP4 (H.264) out of the box.

## Advanced options

A collapsed expansion under the two selects:

- **Orientation**: **Auto (detect from clips)** (default), Landscape (16:9), Portrait (9:16), Square (1:1). When the source and target aspect ratios differ, [face-aware cropping](../pipeline/face-aware-cropping.md) keeps faces in frame.
- **Scaling Mode**: Smart Crop (keep faces), Fill (crop), Fit (letterbox), Blur (blurred background). The UI defaults to Smart Crop; the CLI and config default to `blur`.
- **Transition Style**: **Smart (mix of fades & cuts)** (default), Crossfade, Cut, None. Smart picks per cut point: crossfade for slow scenes, hard cut for fast action.
- **Add date overlay** and **Keep intermediate files** checkboxes.
- When photos are enabled: "Photos enabled (N found)" and a **Photo duration (seconds)** field (1–10).

<ThemedScreenshot name="step3-advanced" alt="Advanced generation options" />

## Title

**Title** and **Subtitle** fields pre-filled with the pipeline's suggestion (LLM-generated when content analysis is on, template otherwise), a **Language** select (auto, en, fr, de, es, it, nl, pt, ja, ko) and a **Regenerate** button. Trip memories also show chips with the detected trip and map mode. See [Title Screens & Maps](../pipeline/title-screens-and-maps.md).

## Music

The **Background music** select has up to three entries:

- **None**: original clip audio only.
- **Upload file**: a **Select music file** picker (`.mp3`, `.m4a`, `.wav`) and a **Music volume** slider.
- **AI Generated**: only listed when `ace_step.enabled` or `musicgen.enabled` is set in your config, and then it is the default. Shows the volume slider and a **Generate Music** button so you can hear the track before rendering; **Regenerate Music** tries again. See [Audio & Music](../pipeline/audio-and-music.md).

## Summary

Stat cards for Clips, Duration, Resolution and Music, then **Back to Clip Review** / **Next: Preview & Export**.

Hardware acceleration is not shown here; it is auto-detected at encode time. Run `immich-memories hardware` or `immich-memories preflight` to see what your machine offers.

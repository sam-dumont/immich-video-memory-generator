# Year in Review

A whole calendar year, chronological, with a title card wherever the month changes. The default target is 10 minutes, and a thin year will not reach it: the cut reports how much it found and how far short it landed rather than padding. `--duration 300` asks for five minutes instead.

The editor prepares a description and facts for every eligible picture in the year, weighs the year's stories against each other in words, and grants each one the pictures its weight earns, capped by the moments it actually holds. The year is partitioned by month, and a plan that leaves a month with worthy material silent comes back as incomplete.

## CLI

```bash
immich-memories generate --memory-type year_in_review --year 2025
```

The date range is exactly 1 January to 31 December. `--month` narrows it to one month, `--start`/`--end` replaces it outright. `--person "Riley"` turns it into a "Your year with Riley" cut: the same monthly structure, only pictures holding that person. Two names means pictures holding both, unless you pass `--person-match or`.

`--birthday` does **not** apply here. It is read only for `--memory-type person_spotlight` (and for a bare `--year --birthday` with no memory type). See [Person Spotlight](./monthly-person-season.mdx).

Photos are in the pool already (`photos.enabled` defaults to true). The flag that matters is the one that takes them out:

```bash
immich-memories generate --memory-type year_in_review --year 2025 --no-photos
```

## Web UI

Pick **Year in Review** on the [Memory page](../web-ui/memory.mdx) and the year from the dropdown.
Its optional **Only with** box narrows the year to one or more people:
the same thing `--person` does above. A second name brings up a **Together /
Any of these people** toggle, the UI's word for `--person-match`. When the
condition is neither a flat AND nor a flat OR, **Advanced people condition**
under the picker takes `'"Riley" AND ("Casey" OR "Bob")'`, the same string as
`--people-expression`.

## Monthly dividers

A divider screen ("January", "February") goes in wherever the month changes between clips. They only appear when the range spans four or more months: `get_divider_mode()` returns "none" for anything shorter, so a February-to-March video has no dividers at all.

## Every month has to have a voice

The year is partitioned by month and the plan is checked against those partitions afterwards. A month with worthy material that ends up with nothing raises an uncovered-partition violation and the run's verdict becomes `coverage_incomplete`. Nothing reserves a slot per month up front; it is a requirement in the brief and a check on the result.

That check is also the tell that you picked the wrong type. If everything you have is one summer trip, a [Season](./monthly-person-season.mdx) or [Trip](./trip-memories.mdx) memory fits the material, and the complaining stops.

## The first cut is the slow one

Every eligible picture in the year gets its description and facts prepared once. The second cut reuses them, so put the cold run on a night you are not watching. See [Editorial annotation setup](../../deploy/configuration/editorial-preparation.md).

# Monthly, Person, Season & On This Day

Five memory types with the same shape: pick a time range, optionally filter by person, cut. They differ in scope. Every duration below is an editable default rather than a cap, and the web UI and the CLI read the same preset for it.

## Monthly Highlights

One month, 60 seconds by default. The title screen shows the month and year ("July 2025"), and there are no month dividers because there is only one month.

```bash
immich-memories generate --memory-type monthly_highlights --month 7 --year 2025
```

Use it on a month you actually shot in. A month of commutes gives it nothing to work with.

## Person Spotlight

A year narrowed to the pictures containing one person, which needs Immich face recognition set up and the person tagged. Every memory type is edited the same way (see [The Curator](../pipeline/the-curator.md)); what makes this one a spotlight is the filter, not a different editor.

```bash
immich-memories generate --memory-type person_spotlight --person "Riley" --year 2025
```

Default duration: about 60 seconds per month, capped at 10 minutes, so a full calendar year asks for 10 minutes on both the CLI and the web UI. `--month` narrows it to one month; `--start/--end` replaces the range outright.

Anchor it on the person's birthday instead, reading the birth date from Immich:

```bash
immich-memories generate --memory-type person_spotlight --person "Riley" --year 2025 --birthday
```

That is a different memory: the year **ending** on the 2025 birthday, plus each of the five previous birthdays as a ±1 day cutaway. It asks for 10 minutes on both surfaces. See [Birthday Compilations](../recipes/birthday-compilations.md).

## Multi-Person

Moments featuring several people. The default is **Together (AND)**: a clip,
Live Photo, or photo qualifies only when every named person is tagged in it.
Two people who were never in the same frame produce an empty memory, not two
solo reels.

```bash
immich-memories generate --memory-type multi_person --person "Riley" --person "Bob" --year 2025
```

Use **Any of these people** in the web UI (or `--person-match or` on the CLI) to make
one memory from every tagged appearance of any named person:

```bash
immich-memories generate --memory-type multi_person --person "Riley" --person "Bob" \
  --person-match or --year 2025
```

AND and OR across the whole list are the two shapes a picker can express. When the
memory you want is neither, `--people-expression` takes the condition itself:
quoted library names with `AND`, `OR` and parentheses, `AND` binding tighter than
`OR`.

```bash
immich-memories generate --memory-type multi_person --year 2025 \
  --people-expression '"Riley" AND ("Casey" OR "Bob")'
```

That one is every picture or video holding Riley and at least one of the two
adults. `AND` means the same asset, not the same afternoon. The expression names
its own people, so it replaces `--person` and `--person-match` rather than
refining them: passing both is a usage error. The web UI has the same field,
**Grouped people condition**, under the people picker's **Advanced people
condition** panel. It covers date-range memories; trips, albums and a
single-person birthday are refused.

Default duration: the same one-minute-per-month rule as Person Spotlight, capped
at 10 minutes. Title screens and default filenames say whether the people are
joined by AND or OR, so the two runs cannot overwrite one another.

The same AND default applies wherever you name several people. Repeating
`--person` on any CLI memory type can be changed to a union with
`--person-match or`, and the Memory page's ordinary **Only with** picker offers
the same **Together / Any of these people** toggle once a second name is in it:

```bash
immich-memories generate --memory-type season --season summer --year 2025 --person "Riley" --person "Bob"
```

## Season

One season out of one year, 2 minutes 15 seconds by default (the preset's own `default_duration_seconds`, about 45 seconds a month).

```bash
immich-memories generate --memory-type season --season summer --year 2025
```

The hemisphere flag controls which calendar months map to which season:

```bash
# Southern hemisphere: summer = December-February
immich-memories generate --memory-type season --season summer --year 2025 --hemisphere south
```

Worth it when the material clusters in a season rather than spreading over the year: summer holidays, autumn walks.

## On This Day

Every previous year, ±1 day around today's date, in one 45-second cut. No `--year`: it looks back from today, over all years that have data, up to 30 years.

```bash
immich-memories generate --memory-type on_this_day
```

Limit the reach with `--years-back`:

```bash
immich-memories generate --memory-type on_this_day --years-back 3
```

It wants three or more years of library behind it, and it is the obvious one to put on a daily schedule.

### Pinning the day

Left to itself this memory asks a different question every day, which is fine for a
daily nostalgia clip and useless for anything you want to run twice. `--day` names the
anniversary to look back from:

```bash
immich-memories generate --memory-type on_this_day --day 2026-08-31 --years-back 20
```

Same day, same years, same cut, so the run can be repeated, compared against an earlier
one, or handed to someone else. Without the flag nothing changes: the run covers the day
it fires.

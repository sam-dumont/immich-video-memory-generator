# Where the fixture library comes from

Every picture in this directory is a CC0 1.0 (public domain dedication) stock
photograph: the six StockSnap originals the library started with, and the rest
fetched from Wikimedia Commons with the licence statement filtered to CC0
(P275 = Q6938433) and checked again on each file's own metadata before download.
CC0 asks for nothing: no attribution, no share-alike, no commercial restriction.
The provenance is recorded anyway, with a SHA-256 of the file as shipped
(EXIF stripped, long side 1280 px, JPEG quality 82), so `tests/test_fixture_library.py`
can prove every file is the one credited here.

None of these is anyone's real library. The clips the fake Immich serves are pans
over these same photographs, made at test time, so no video needs a credit.
`captions.json` records the visible content of each photograph used by the fake
library, keyed by its filename without the extension. The story, capture dates
and people in `fake_library.py` are a script, not facts about these stock photos.

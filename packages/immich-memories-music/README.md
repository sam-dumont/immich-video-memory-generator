# immich-memories-music

Bundled royalty-free background music for
[immich-memories](https://github.com/sdumont/immich-video-memory-generator).

Installed with the `music` extra:

```bash
pip install "immich-memories[music]"
```

Every track was generated locally with ACE-Step 1.5 — nothing is sampled from or
derived from third-party recordings, so there is no licence to track and no
attribution required. See `LICENSE-MUSIC` for the models, settings and per-track
tempo, key and seed.

Tracks are grouped by mood, one folder per mood, which is how `LocalMusicSource`
picks between them.

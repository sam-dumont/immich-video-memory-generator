# User Guide

Choose a period, person or album from your Immich library, review the selection, and export a
memory video. The current walkthrough lives on the docs site:

| Topic | Page |
| --- | --- |
| Installation and first run | [Quick start](https://sam-dumont.github.io/immich-video-memory-generator/docs/welcome/quick-start) |
| Brief, selection and export | [Memory page](https://sam-dumont.github.io/immich-video-memory-generator/docs/create/web-ui/memory) |
| Server and account settings | [Settings](https://sam-dumont.github.io/immich-video-memory-generator/docs/create/web-ui/settings) |
| Commands and flags | [CLI reference](https://sam-dumont.github.io/immich-video-memory-generator/docs/reference/cli-reference) |
| Configuration | [Config reference](https://sam-dumont.github.io/immich-video-memory-generator/docs/reference/config-reference) |
| Failures and slow runs | [Troubleshooting](https://sam-dumont.github.io/immich-video-memory-generator/docs/reference/troubleshooting) |

Authentication is off by default. Configure it before exposing the UI beyond localhost. The app
supports one user flow in one replica; generation reads from Immich and upload-back is opt-in.
